# 前端服务适配

- `aiService.ts`：提交本机后端 AI 任务并订阅 SSE 结果，向 UI 提供进度与错误；不保存密钥或直接请求模型提供方。
- `vocabKnowledge.ts`：本地词表初始化、查询和缓存复用。
- `backup.ts`：本地数据导出、导入和兼容处理。
- `theme.ts`：只管理白天/夜间 UI 偏好；`?theme=day` 可临时以白天主题打开，不覆盖已保存的偏好。手动切换才写入独立的主题存储项。
- 演示样例模块：导入明确标注的虚构随笔，不调用模型。
- `mockAI.ts`：保留的历史模拟实现，不是当前真实模型主路径。

模型提示词、请求与结果解析放在根目录 `server/`。前端服务负责接口适配和用户本地数据。
