# 本机后端

Node 原生 HTTP 服务负责模型设置、AI 任务执行、结果解析及 SSE 推送；入口只组装模块并启动。开发时监听 `127.0.0.1:4318`，前端通过 Vite 代理访问 API；构建后 `npm start` 同时提供 `dist` 页面。

Key 来自项目根目录 `.env.local` 或 `.local/ai-settings.json`，均忽略提交。客户端提交 `/api/ai/tasks` 后订阅任务结果，不直接调用模型。用户笔记的长期保存仍由浏览器 IndexedDB 负责。

当前服务面向本人本机使用；公开部署前需另外完成访问控制和目标环境适配。根目录 README 给出启动命令与设置方式。
