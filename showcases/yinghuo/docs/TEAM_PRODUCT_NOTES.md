# 萤火 — 团队内部产品备忘

> 对外宣传请另写用户向文案；本文供开发/设计对齐用。

## 一、阶段与解锁（草案）

| 节点 | 解锁名 | 行为（产品向） |
|------|--------|------------------|
| **50 篇** | **知己** | 可上传人脸图、声音等素材入口，为后续「自我/数字人」打底。 |
| **300 篇** | **自我** | 数字人以更稳定、更有力量的方式呈现；衔接「光掩面 / 召唤露脸」与音频线。 |

## 二、形象叙事（萤火虫美学）

1. **初期**：一团模糊荧光。  
2. **中期**：立体可互动，但仍是「萤火虫」气质的一团光。  
3. **随篇数增加**：渐具人形轮廓，**本质仍是萤光**（非写实人突然占屏）。  
4. **后期**：结合用户高矮胖瘦、照片等生成可辨识虚拟自我。  
5. **日常 vs 召唤**：平时**光掩面**；**仅用户主动召唤**时短暂显现更像自己的样貌。  
6. **技术路径**：3D/人脸扫描为**可选项**；优先可做 2D/粒子/光效以控成本。

## 三、声音与冥想（300 篇后，草案）

- 使用用户上传声音做**声音克隆**，生成**自我肯定冥想**等音频内容。  
- 与形象线可同阶段或略晚，由排期决定。

## 四、冥想模式（随笔顶栏内嵌）

### 4.1 行为

- **入口**：打开某篇随笔后，顶栏日期/金句操作条左侧 **「冥想」** 开关（`Wind` 图标）。  
- **开启时**：顶栏矩形 **四条边** 按 **上 → 右 → 下 → 左** 顺时针轮流高亮（蛇形），每边 **4 秒**，对应 **鼻吸 → 屏息 → 鼻呼 → 屏息**，与方盒呼吸一致。  
- **震动（可选）**：仅在 **冥想已开启** 时显示小图标；在 **每条边切换到下一边** 的瞬间 `navigator.vibrate(32)`（与流光同步，非独立定时器）；桌面端可能无效果。  
- **关闭冥想**：自动关闭震动选项。

### 4.2 技术

- 样式：`index.css` 中 `.meditation-flow-ring` / `::before` / `.meditation-flow-inner`。  
- 逻辑：`NoteEditor.tsx` 内 `meditationMode`、`meditationVibrate` state + `setInterval(4000)`。

### 4.3 后续可扩展

- 与「自我」形象、方盒呼吸可视化叠在同一顶栏或浮层。  
- 300 篇后 TTS/克隆声线音频。

## 五、与 Netlify / 数据
