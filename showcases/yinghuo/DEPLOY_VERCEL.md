# Vercel 部署边界

当前项目包含本地 Node AI 后端。按旧方法选择 Vite 并上传 `dist`，只能发布前端，不能自动提供 `/api/ai/tasks` 及 SSE 服务。

## 目前推荐的验收方式

在项目根目录运行 `npm install`、`npm run build`、`npm start`，打开 `http://127.0.0.1:4318`。模型设置在后端完成，见 [README](README.md)。不要将 API Key 作为 `VITE_*` 构建变量。

## 云端迁移前的工作

1. 确定 Node 后端的运行位置，验证任务执行和 SSE 在目标环境中的生命周期。
2. 规划前端 API 转发、HTTPS、用户访问权限和服务端设置持久化。
3. 配置后端密钥，验证真实模型调用及失败提示。
4. 使用备份导入迁移浏览器本地数据；域名或端口变化不会自动搬迁 IndexedDB。

本次未发布到 Vercel，也未将当前长连接任务接口适配为平台函数。当前文档记录完整部署还缺的工作，不能用静态发布替代后端验收。
