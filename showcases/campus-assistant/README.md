# 华农校园百事通AI智能体

暑期实习企业协作项目。本人担任项目负责人，与润建股份协作推进校园服务智能体的阶段建设。

[访问项目](https://hzau.rundecloud.com/) · [统一展示台](http://127.0.0.1:8000/showcase) · [演示顺序](../../docs/demo.md)

## 项目目标与阶段成果

把分散的校园资料整理为可检索知识，帮助学生查找办事信息，并通过业务工作流承接具体服务需求。

| 阶段成果 | 内容 |
| --- | --- |
| 262份知识文档 | 已完成清洗与整合 |
| 10个知识板块 | 学生生活、学生组织、其他事项、竞赛、新生入学、农业相关、教务系统、学校介绍、心理健康、学生管理 |
| 11个业务工作流 | 面向校园服务需求编排问答与业务处理流程 |

阶段规模据项目工作简报统计。

## 项目角色与团队实现

团队完成的主要技术工作：

- **前端体验：** React 18 / Vite响应式界面，支持问答、虚拟形象、语音、资源卡片、文件查看和反馈。
- **服务与数据：** Node.js、PostgreSQL、Redis、Prisma与Dify后端，支持流式输出、鉴权、日志、反馈记录和模型接口切换。
- **知识可靠性：** 知识检索、来源引用、低置信度拒答，并使用本地模型校验知识库内容。

## 下一阶段

推进校内服务器与存储部署、二级域名、统一身份认证及业务系统接入，协调资料授权和师生测试反馈。2.0计划扩展面向不同角色的校园服务，在授权范围内聚合动态校园资讯，并对非官方内容标注来源和时效。
