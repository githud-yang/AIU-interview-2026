# YOLO：先建立研究问题，再匹配投稿要求

核查日期：2026-10-11。本文是带来源的首批人工策划与官方规则核查，不是自动化期刊背调系统，也不是录用承诺。本轮复核三刊范围/作者指南，并补充近期已发表论文样本；具体阅读范围逐条记录。尚未系统阅读各刊全部相关论文、编辑社论与补充材料，未取得正式编辑回复。

## 展示时如何讲

“我先把期刊的明确要求、已发表论文的证据结构和自己研究的差距分开。实时部署方向优先评估JRTIP；若形成图像处理方法贡献，再评估SIVP；若做严格系统实证，也可以评估PLOS ONE。现在已有三刊来源卡和初步差距分析，尚未把期刊检索、政策更新和实验排程自动打通。”

中文讲解与投稿语言分别处理：演示使用中文研究解读；选定目标刊后再生成并校核适用的投稿语言。PLOS ONE明确要求标准英文，不能据此把本地展示页也做成全英文。[发表标准第5条](https://journals.plos.org/plosone/s/criteria-for-publication)

## 当前判断

固定权重比较320/480/640输入尺寸，适合建立测量管线和找到现象。它本身不足以证明新方法贡献。公开COCO样例可能与预训练重叠，不能作为独立泛化证据。把这项实验定位为前期摸底，后续实验由研究问题和目标期刊要求决定。

## 三条候选灵感与反证路径

| 候选问题 | 可检验假设 | 已有工作警示 | 必须补的证据 | 当前状态 |
| --- | --- | --- | --- | --- |
| A：有截止时间和负载波动时，如何选择YOLO输入尺寸？ | 结合场景信息与剩余时间的策略，相比固定尺寸/简单负载规则，能降低超时并保留有效检测质量 | ROMA已研究动态视频内容、延迟和检测器选择；不能把“动态切换”本身当创新 | 实际视频时间线；固定尺寸、简单规则、已有动态方法对照；策略开销；P95/P99、deadline miss、丢帧与流式精度；独立场景 | 建议优先进一步检索；未实现策略，未证明新颖性 |
| B：低分辨率丢失的小目标，能否有选择地补救？ | 仅在特定高风险区域执行二次检测，比全帧高分辨率更节省计算，同时减少小目标漏检 | 多尺度/区域处理属于已有方法族；必须寻找高度相似工作 | 目标尺寸分层结果；区域选择器成本与失败；全帧/固定裁剪/自适应区域对照；独立测试和消融 | 候选，尚未查清最接近方法和实现条件 |
| C：离线选出的最快配置，在持续运行时还可靠吗？ | 将预热后延迟分布和持续负载纳入选择，能比只看平均FPS得到更稳定的部署配置 | 已有实时/流式感知研究，不能仅增加一张速度表 | 持续运行日志；不同设备/负载；端到端P95和超时率；离线与在线选择对照；复现实验 | 可从现有测量扩展，但跨设备资源尚缺 |

初步相关工作：[ROMA，WACV 2023](https://openaccess.thecvf.com/content/WACV2023/html/Lee_ROMA_Run-Time_Object_Detection_To_Maximize_Real-Time_Accuracy_WACV_2023_paper.html)、[Real-Time Object Detection for Streaming Perception，CVPR 2022](https://openaccess.thecvf.com/content/CVPR2022/papers/Yang_Real-Time_Object_Detection_for_Streaming_Perception_CVPR_2022_paper.pdf)。本轮只核对摘要/入口，不能称已完成创新查重。

每个候选都需补“最接近的3–5篇工作→做法差异→可以推翻假设的结果→最小实验”。若差异只是换YOLO版本、数据集或拼接常见模块，先降级为工程复现，不自动生成创新结论。候选A目前优先，是基于现有设备、关注速度的目标和JRTIP范围作出的工程判断，并非期刊认可。

## 三刊对比：规则、观察与差距

| 期刊 | 官方筛选重点 | 近期样本带来的研究启发（推断） | 当前最关键差距 |
| --- | --- | --- | --- |
| JRTIP | 必须实质处理实时问题，单报速度不够 | 并发边缘视觉的吞吐/功耗研究提示：可以围绕负载干扰和部署约束建立问题，而非只加FPS表 | 缺真实时间约束、持续负载、策略与已有方法对照；当前仅固定尺寸测量 |
| SIVP | 图像/视频处理理论与工程贡献；LaTeX模板和PDF；页限存在官网冲突需核实 | YOLOv6+从INT8量化误差出发，在真机比较精度、时间、功耗，提示要解释“为什么有效” | 缺方法机制、训练或量化实现、消融与真机验证；当前无新方法 |
| PLOS ONE | 原创或有科学理由的复现、技术严谨、结论由数据支持、充分报告与数据可用性 | GS-YOLO的跨数据集、组件消融和失败分析提示：完整证据链比只报最优结果更有说服力 | 小样例可能与预训练重叠，缺独立评测与稳健性依据；当前不支持广泛结论 |

这些观察来自少量明确列出的样本，不能推出期刊整体“偏爱某模块”、录用率或编辑个人偏好。下列规则以官方页面为证，观察以论文为证。

## 三个期刊的首批背调

### Journal of Real-Time Image Processing（JRTIP）

官方关注图像/视频算法、软硬件实现的实时问题。作者指南明确：只报告处理时间或速度不算充分处理实时性；cover letter须说明解决了什么实时问题。稿件采用该刊双栏格式，12页上限包括参考文献与作者简介；原创研究需数据可用性声明，提交时需适用的作者贡献/利益声明及可编辑源文件。官方另有写作工具使用与作者责任政策，正式投稿时逐项核对。[范围](https://link.springer.com/journal/11554/aims-and-scope)、[作者指南](https://link.springer.com/journal/11554/submission-guidelines)

对本项目的推断：A/C比单纯尺寸扫描更贴近范围，但需要明确的实时问题、对照和实测贡献。现有小样例、单设备尺寸比较不能据此标“可投稿”。

[近期文章目录](https://link.springer.com/journal/11554/articles)已查看。代表样本[Modeling throughput and power consumption for real-time concurrent vision application deployments on edge](https://link.springer.com/article/10.1007/s11554-026-01915-y)，发表于2026-08-17；本轮只读官方摘要与元数据，付费方法全文未取得。摘要围绕并发视觉负载的资源争用、通信、动态频率和热效应建立吞吐/功耗模型，并报告跨边缘平台验证。**本项目推断**：A/C应把负载与系统约束作为待解释变量，补持续运行和平台证据；这篇不等于已完成最接近工作比较，也不证明期刊统一偏好。

联系：官方[联系页面](https://link.springer.com/journal/11554/contact-the-journal)提供支持入口。本轮没有找到“保证接受投稿前范围询问”的明确规则，状态为待确认；先向官方渠道核实适当联系对象，再使用下面的草稿。没有查找或联系匿名审稿人。

### Signal, Image and Video Processing（SIVP）

官方范围覆盖信号、图像和视频处理理论、实践及工程解决方案。当前作者指南的专门提交格式要求LaTeX `sn-jnl`模板和PDF，摘要150–250词、4–6个关键词及适用声明。**官网页限存在冲突**：作者指南“Page Count”写正文双栏不超过10页、参考文献可另占页；范围页仍写10页含全部内容且第10页仅参考文献。准备稿先按较严口径，正式提交前向官方编辑渠道核实，不把其中一个口径当成已解决。[范围](https://link.springer.com/journal/11760/aims-and-scope)、[作者指南](https://link.springer.com/journal/11760/submission-guidelines)

代表样本[YOLOv6+: simple and optimized object detection model for INT8 quantized inference on mobile devices](https://link.springer.com/article/10.1007/s11760-025-04234-0)，发表于2025-05-28；本轮读官方开放HTML的摘要、方法与实验设置/结果，未复现代码或逐图检查原始表格。文章以量化误差为具体机制，比较组件、INT8性能及手机端时间/功耗。**本项目推断**：B若走方法路线，需要机制、受控比较与部署实测；“换输入尺寸”本身不满足这类证据结构。

对本项目的推断：若最终贡献更偏应用方法、误检/漏检改善，而非截止时间保证，可以进一步评估B与该刊的匹配；范围覆盖不等于创新和实验门槛已经满足。需阅读全文查最近似方法及完整对照。投稿前咨询是否受理、具体联系对象仍未核实，不把“官网有联系方式”当作邀请发送推销信。

### PLOS ONE

官方要求原创研究、技术可靠、结论由数据支持、充分报告及数据可用性；衍生/重复研究需要合理科学理由。其审稿重点是技术与科学有效性，不按影响力高低筛选。开始投稿页面明确**不受理投稿前咨询**；投稿cover letter另有一页上限及内容要求。[发表标准](https://journals.plos.org/plosone/s/criteria-for-publication)、[审稿人指南](https://journals.plos.org/plosone/s/reviewer-guidelines)、[开始投稿](https://journals.plos.org/plosone/s/getting-started)、[提交指南](https://journals.plos.org/plosone/s/submission-guidelines)

代表样本[GS-YOLO: A lightweight high-accuracy model for small target detection in drone aerial images](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0350840)，发表于2026-06-08；本轮读官方HTML的摘要、数据说明、比较、消融与失败讨论，未复现权重或独立审计数值。文章报告VisDrone/UAVDT评测、组件消融和遮挡失败案例。**本项目推断**：应补独立评测、现有方法对照、失败样例与数据记录；少量已发表样本不能证明“加注意力模块容易录用”，也不能替代本项目的创新检索。

对本项目的推断：可靠复现/系统实证研究可以评估，但不能把“不按影响力筛选”误读为没有原创性、样本量或实验要求。当前COCO小样例不够支持广泛结论。不要给该刊发presubmission inquiry；如最终选它，应准备符合要求的完整研究与cover letter。

## 从背调到实验的具体缺口

| 证据任务 | 验收材料 | 当前状态 |
| --- | --- | --- |
| 最近似工作比较 | 每方向3–5篇全文，记录任务/数据/硬件/计时范围/方法差异/失败条件 | 少量入口与样本已查，系统矩阵未完成 |
| 实时问题定义 | 真实应用deadline、输入到输出的时间边界、持续负载协议 | 未建立；不能用平均FPS替代 |
| 方法贡献 | 固定尺寸、简单规则、最近似方法和策略开销的受控对照 | 自适应策略未实现 |
| 独立性与复验 | 无已知泄漏的数据划分、跨场景或设备协议及重复依据 | 当前样例有预训练重叠风险；跨设备未做 |
| 完整结论 | 原始CSV、负结果、失败案例、可访问数据与环境说明 | 当前尺寸测量已保存，独立重放入口未实现 |
| 投稿规格 | 确定刊物/文章类型/页限/模板/声明/费用路线 | 首批规则已核查；未形成可提交稿 |

## 系统调整顺序

1. 保存带来源和核查日期的期刊要求；未知项保留未知。
2. 生成候选问题，检索最接近工作，记录反证和淘汰原因。
3. 将期刊要求转成实验缺口：数据、对照、实时性、重复、消融与声明。
4. 缺口补齐后再进入正式研究和稿件；当前尺寸实验只做前期测量。
5. 起草适用的编辑咨询/cover letter；确定收件方和内容后才进入发送或提交步骤。
