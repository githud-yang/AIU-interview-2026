# 运行证据

- `coco8_baseline_*/`：由实际训练目录归档的 CSV、曲线、配置、验证图片、哈希与环境快照；最新位置见 `../training_result.json` 的 evidence_dir。
- `yolo-public-sample.jpg` 及对应 JSON：本机 best.pt 对 Ultralytics 安装包公开 bus.jpg 的真实检测。公交车与行人是公开样例，非用户摄像头图。
- `yolo-runtime-smoke.json`：真实 HTTP 双视频流、停止和三帧本地视频释放核验。

原摄像头黑帧只保留在本机并被 Git 忽略。此目录保存训练与公开推理证据，不含网页截图；先前科研桌面布局已有本人截图确认，最新统一展示台、科研订阅改版及小屏尚无浏览器视觉实测，不能用本目录的接口/推理证据替代布局检查。归档时间、最佳权重验证指标、最后一轮指标与归档时环境各自记录。

从[统一展示台](http://127.0.0.1:8000/showcase)可集中查看公开证据并进行只读预检；预检不启动研究、摄像头或云端模型。科研与萤火运行摘要另见根目录[evidence](../../evidence/README.md)。
