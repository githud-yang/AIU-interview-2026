# 面试演示（约 5 分钟）

1. 打开 README，说明基础题与进阶题的边界，以及用一个服务减少环境复杂度的取舍。
2. `ollama list` 展示模型；`python scripts/verify.py --live` 展示真实工具调用及网页游戏 API。
3. 启动网页，在“终端迷局”输入“看看终端屏幕”，再选择一项行动，展示连续剧情。
4. 打开 YOLO 页，点启动，将常见物体放在镜头内，展示框和类别；点停止释放设备。
5. 展示 `docs/training_result.json`、本机 `runs/detect/` 的训练曲线和 best.pt，说明 coco8 的局限。
6. 展示 Git 提交、工程日志和 AI 使用情况；说明硬件及完整 Harness 尚未实现。

准备回答：模型请求如何到达 Ollama？工具输出如何回传？为什么训练只有 8 张图？训练后的权重如何进入网页？为什么摄像头只开一次？如何区分“写了代码”和“实际验证”？

不要把样例数据的指标解释成真实环境准确率，也不要把会话列表解释成长久记忆。社交协作要求由本人用实际联系与交流经历说明。
