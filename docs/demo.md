# 面试演示（约 5–7 分钟）

1. 打开 README 和根目录 PDF，说明基础题、进阶 Harness 与尚未完成的实物/外部验证。基础项目使用一个 FastAPI 服务，科研增加 LangGraph 和 SQLite 持久执行。
2. 用 `ollama list` 展示本地模型；已有真实计算和游戏 API 证据在 verification.md。用 `./scripts/start.ps1 -Background` 启动网页。
3. 打开 [科研工作台](http://127.0.0.1:8000/research)，先展示已完成运行 `dd98c3f59cc34e73b7d2be3e3ec36899`：12 阶段、真实事件、7 次模型请求、18 次拟合与 0 次研究内人工介入。已有样例约 7.6 分钟，面试可展示完整保存记录，不必现场等全程结束。
4. 解释文献—协议—固定划分—验证候选—冻结最终测试—CSV—稿件的衔接；打开原始结果和 PDF，对照展示干净准确率的下降与噪声准确率的提升。基线与无增强消融共享对照、SD 不是置信区间；当前实验是已知方法的小样例，不把它讲成创新论文。
5. 展示原稿、审查意见、第二版和保留冻结测量的最新第四版讨论正文。论文分析、审查、修订使用已登录的本机 Codex CLI，实际调用保留日志；DeepSeek 可在“论文模型设置”填 Key、测试连接并保存后即时启用，当前未有真实密钥调用验证。默认持续到本轮完成，资源计数用于记录，高级限额由用户主动设置。页面可以取消/恢复；完成步骤由账本复用，恢复不会清零计数。
6. 打开 [文字冒险](http://127.0.0.1:8000)，推动一次剧情；打开 [视觉检测](http://127.0.0.1:8000/yolo)，选“公开静态样例”，展示真实检测框后停止。明确静态图与现场摄像头是两类验收；现场镜头正常时再演示真实物体。
7. 展示 training_result.json、训练曲线与 best.pt，说明 30 轮、最佳验证和最后一轮指标不同，coco8 仅 4 张训练/4 张验证图。打开主清单解释任意代码沙箱、通用领域、外部研究质量和实际投稿仍待实现。
8. 展示 MCP 八工具、项目 skill 和 Git 提交。MCP/技能用于智能体直接操作同一工作台 API，新会话加载配置；不声称当前聊天已经热注入。社交协作经历由本人如实补充。
