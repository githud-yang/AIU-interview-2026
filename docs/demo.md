# 统一展示台演示（建议6–8分钟）

首入口：[统一展示台](http://127.0.0.1:8000/showcase)。总览、逐项演示、公开证据与只读预检集中在此，按基础→YOLO→萤火→硬件→Harness→工程与AI披露的顺序讲解。6–8分钟是彩排建议，页面没有演示时长限制；面试官追问时可展开对应材料。

## 开始前

在仓库根目录执行`./scripts/start.ps1 -Background`，萤火按[独立项目README](../showcases/yinghuo/README.md)单独启动。本地模型可用`ollama list`展示。打开展示台的只读预检，核对本机Ollama模型列表、权重与状态、萤火健康接口和科研模块是否加载；预检不会发起生成、研究或摄像头命令，在线状态不等于功能验收。

展示时用“下一项”或方向键顺序切换，通过新标签打开作品以保留展示台，公开证据可在弹窗查看。备好公开图检测结果、训练曲线、保存的研究运行、萤火虚构日记和实际硬件项目。展示保存结果即可说明已有工作，不需要现场重训或重新启动完整研究。若准备演示萤火实时AI，先在其本机页面确认Key与网络；预写演示译文必须说明是样例。
